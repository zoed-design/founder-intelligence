# Product roadmap

## From prototype to connected construction workspace

The prototype demonstrates a small part of the wider product mission. These are the next capabilities we intend to build.

| Capability | Current prototype | Roadmap |
| --- | --- | --- |
| Site information | Browser image upload, manual message import and conversation interface | Connected messaging, project files and site updates |
| Project knowledge | Reviewed project facts, rule-based retrieval and source links in the session Wiki | Persistent Wiki linked to project records and schedules |
| Compliance references | Selected official planning references and drawing / OC checklist extracts; site-specific applicability needs checking | Source-linked NCC / ABCB, NSW and Council references with applicable versions |
| Outputs and review | Editable drafts, Digger’s session review queue, local approval and download | Connected delivery with human sign-off and audit records |
| Model / API and conversation context | Local rules and limited follow-up context; no runtime model API | Runtime model/API integration and richer conversation context for natural-language questions across the crew |
| Reliable retrieval architecture | Selected local extracts and source links | Controlled document retrieval, source validation and version-aware references within an improved agent architecture |
| Backend storage and services | Browser-session imports, tasks and review replies | Backend storage, persistent shared knowledge, synchronisation and background services |
| Live weather forecasts | Not connected | Live forecasts linked to project location, construction stage and schedule, supporting site reminders and client updates |

Digger will review proposed actions and programme changes before approval or external use. See the [live-weather requirement](live-weather-roadmap.md) for the future capability’s scope.

The first four roadmap entries are restored from the [16 November 2026 landing page](https://github.com/zoed-design/founder-intelligence/blob/2a356d3ec65b940ac7aee7233ebd21d16790b6bd/landing/index.html). Their roadmap wording is preserved. Current-prototype descriptions reflect the latest release; runtime model integration, richer context, reliable retrieval architecture, backend services and live weather are subsequently requested additions. No implementation dates are committed here.
