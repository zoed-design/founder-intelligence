# Tally: clear, considerate client communication

Tally’s prototype responses use source-based rules, not a newly trained model. The wording follows the practical principles in [NSW Government guidance for builders and tradespeople](https://www.nsw.gov.au/housing-and-construction/compliance-and-regulation/your-obligations-to-your-customers/tips-and-guidance): explain progress clearly, communicate openly and keep clients informed about delays.

## Response pattern

1. Acknowledge why the milestone matters to the client’s planning.
2. Give the supported projected date and a source reference.
3. Distinguish projected dates, reported progress and confirmed completion.
4. Explain potential disruption and what the site team would review.
5. Say that material changes need confirmation and the client will be kept informed as dates are confirmed. Do not claim that an external update was sent.

## Weather boundaries

The current weather feature is **a clearly labelled local demonstration**, selected by the founder. No live weather API is connected and no current weather is asserted. The example week is 18–24 January 2027, near the supplied roof-covering target. Its rainfall and 0–2 working-day roofing allowance are deliberately invented scenario inputs.

Each related message and citation must say that this is simulated. The allowance is not a calculation from rainfall, a professional estimate or an approved program change. Rain-watch days are not automatically lost working days. Do not convert an allowance into a new deadline, especially without a work calendar, holidays, task dependencies, site conditions or available float.

For demolition, concreting, bricklaying, framing and roofing, the app displays stage-specific review reminders to Digger and Roo. Selecting enclosed / after lock-up suppresses the pre-lock-up reminders. This does not establish that all external work is complete. The stage is reported demo context; it is not inferred from a photo.

## Project dates

The supplied project schedule projects roof-covering completion for 22 January 2027. Practical Completion is undated. A separate OC receipt target is not a whole-project finish or permission to move in. Tally must retain these distinctions while using helpful, considerate wording.
