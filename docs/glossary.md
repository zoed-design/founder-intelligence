# Glossary

Use these terms consistently in code, docs and the pitch.

| Term | Meaning |
|---|---|
| **Founder** | The business owner; primary user and approver |
| **Tier** | Access level of a knowledge entry or output: internal, customer-safe, public-approved |
| **Project-scoped** | A role that sees customer-safe records only for its own jobs |
| **Router** | Front-door agent: identifies the sender, locks the tier, picks the agent, escalates |
| **Capture agent** | Turns voice, photos, dockets and messages into text and candidate facts |
| **Curator agent** | Binds items to jobs, checks them against approved documents, flags conflicts, drafts updates |
| **Teamwork agent (SiteBrain)** | Answers site staff and trades; builds certifier packs |
| **Commercial agent** | Claims, variations, procurement coding |
| **Content agent** | Drafts posts in the founder's voice from public-approved knowledge |
| **Draft** | Any proposed outbound action; always starts pending |
| **Review gate** | Where the founder approves, edits or rejects drafts |
| **Escalation** | Routing an item straight to the founder instead of automating it |
| **Conflict** | A field observation or question that disagrees with an approved document |
| **Withheld** | A matching record the asker is not allowed to see |
| **Founder rule** | An internal knowledge entry created from a founder's edit to a draft |
| **Role card** | The five-field definition of an agent: purpose, sources, tier, autonomy, handover |
| **PCA** | Principal certifying authority (the certifier) |
| **Value stream** | Teamwork, Commercial or Brand: the three uses of one fact |
